Riggy Fashion — Risk & Decision Framework

Risk → Control Point → Solution → Owner → KPI → Decision Gate

Leadership view

Each pilot risk should have an owner, measurable KPI and explicit Continue / Adjust / Pause decision.

HIGH

1. Economics / Profitability

Model commission, delivery, returns, payment, packaging, support, discounts and AI cost before scaling.

Owner: Finance + Marketplace
KPI: Contribution margin/order · Decision: Continue / Adjust / Pause
HIGH

2. Customer Acquisition & Switching

Test whether AI-assisted complete looks and local availability create incremental demand.

Owner: Growth + Product
KPI: CAC; conversion; repeat rate · Decision: Continue / Adjust / Pause
HIGH

3. Inventory Accuracy

Use SKU, size, colour, quantity, location and price feeds; reserve stock during purchase.

Owner: Supply Chain + Tech
KPI: Inventory accuracy; cancellation rate · Decision: Continue / Adjust / Pause
HIGH

4. Catalogue Quality

Require structured attributes and quarantine incomplete seller data before AI recommendations.

Owner: Catalogue + Product
KPI: Attribute completeness · Decision: Continue / Adjust / Pause
HIGH

5. Complete-Look Fulfilment

Validate every item before promising a complete look; start with single-node fulfilment.

Owner: Operations + Product
KPI: Look fulfilment; on-time rate · Decision: Continue / Adjust / Pause
MEDIUM

6. Substitution

AI proposes alternatives; customer approves. Show original versus replacement and price/size/colour changes.

Owner: Product + AI
KPI: Substitution acceptance · Decision: Continue / Adjust / Pause
HIGH

7. Returns & Exchanges

Track return reasons, size/fit patterns and return-adjusted contribution.

Owner: Operations + Finance
KPI: Return rate; contribution/order · Decision: Continue / Adjust / Pause
HIGH

8. Rider / Store Capacity

Only show Express when inventory, node and rider capacity support the promise.

Owner: Operations
KPI: SLA adherence · Decision: Continue / Adjust / Pause
HIGH

9. AI Hallucination

AI interprets intent; verified commerce systems provide price, stock, size and delivery facts.

Owner: AI + Tech
KPI: Data mismatch incidents · Decision: Continue / Adjust / Pause
MEDIUM

10. AI Visualisation Trust

Label generated visuals and keep actual SKU imagery/details beside them.

Owner: Product + Design
KPI: Expectation-mismatch returns · Decision: Continue / Adjust / Pause
MEDIUM

11. Customer Data & Consent

Collect only necessary photos/preferences and define consent and retention controls.

Owner: Privacy + Product
KPI: Consent; deletion compliance · Decision: Continue / Adjust / Pause
LOW / V2

12. Custom Designer Fashion

Keep custom production out of V1; pilot later with a small designer cell.

Owner: Partnerships + Operations
KPI: Lead time; fulfilment rate · Decision: Continue / Adjust / Pause
